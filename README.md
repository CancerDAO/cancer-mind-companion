# CancerDAO Cancer Mind Companion

心理支持伙伴 skill。为癌症患者和照护者提供日常情绪陪伴、心理筛查和危机响应。

## Install

```bash
npx skills add CancerDAO/cancer-mind-companion
```

## When to use

- 失眠、焦虑、抑郁、无助、恐惧
- 照护者 burnout
- 任何持续情绪低落

## Key features

- PHQ-4 / GAD-4 简化筛查
- 治疗性沟通技巧（Validation、Reflection、Normalization）
- 危机检测 + 热线资源
- 照护者 burnout 识别
- 情绪日志
